# ×はどこだ

広告をよけて、記事を最後まで読むタイムアタックです。本物の×だけを押してください。まちがえて広告を押すと……。

- 記事は4本（レシピ → 旅行ブログ → ニュース → 家電レビュー）。読み切ると次の記事が開きます。先へ進むほど広告が増えます。
- 広告は19種類。小さな×、枠の外の×、5秒待つと出る×、「本当に閉じますか？」、通知の許可、アプリへの誘導、スキップできる動画など、本物のサイトにある形です。どれが出るかは毎回変わります。
- **今日の1本**：毎日1本、だれが遊んでも同じ広告の並びになります。続けて読み切ると「🔥◯日連続」が残ります。
- **挑戦状**：結果の文に付くリンクを送ると、受け取った人はあなたのタイムを相手にその場で挑戦できます。
- **上級**：ふつうで読み切った記事は上級が開きます。難しい広告（★2〜3）だけが出て、ヒントは使えません。
- **メダル**：記事ごとの目安のタイムで 🥇🥈🥉。結果に「金まで あと◯秒」が出ます。
- **広告図鑑・記録**：閉じた広告の名前と閉じ方が図鑑に残ります（19種類）。読み切った回数・閉じた広告・感染した回数・メダルの数も見られます。
- **ベストとの差**：自己ベストのときに広告を閉じた時刻を覚えておき、次からは閉じるたびに「ベストより◯秒 速い／おそい」が出ます（記事を読むときだけ）。
- **ロング**：記事1〜3を読み切ると開きます。その3本の記事をつないだ長いページで、広告は12枚です。先へ進むほど難しくなり（★1→★2→★3を4枚ずつ）、並びは遊ぶたびに変わります。まちがえたら、何枚まで閉じたかが残ります。
- **次の目標**：メニューに、次にやること（つづきの記事 → 金メダル → 上級 → ロング）を1つだけ出します。押すとすぐ始まります。
- **上級の日**：日曜の「今日の1本」は、難しい広告だけ・ヒントなしになります。
- **実績**：15個（ヒントなしで読み切る・上級で金・7日連続・図鑑コンプリートなど）。取れると結果の画面に出て、図鑑の画面で一覧（まだのものも条件）を見られます。
- **練習**：図鑑の見つけた広告は「練習」で1枚だけ試せます。時間も記録も残らず、まちがえても閉じ方が出るだけです。
- ヒントを見ると+5秒。記事ごとのベストと、全部の記事の合計タイムが残ります。結果は X・LINE・端末の共有・コピーで送れます（送るのはあなたが押したときだけ）。
- 広告・サイト・商品はすべて架空です。本物の広告は入っていません。記録はあなたのブラウザにだけ残り、外へは送りません。
- 文字の形（フォント）だけ Google Fonts から読み込みます。そのとき、ふつうのサイトと同じく IP アドレスなどが Google に届きます。一度読み込めば端末に保存し、次からは使い回します。
- ホーム画面に追加すると、アプリのように開けます。一度開けば、電波が無くても遊べます。
